## Quick Reference

### Placeholder Patterns
When using placeholders like `my-binding`:
1. Replace with actual variable, function, or property names
2. Use meaningful names that represent the binding purpose
3. Verify definitions and correct usage
4. Document the binding's role in the system

### Code Review Checklist
- [ ] Variables have descriptive names
- [ ] Bindings are properly defined
- [ ] Context is clear and documented
- [ ] Error handling is implemented
- [ ] Code follows project conventions
