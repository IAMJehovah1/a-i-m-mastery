Multi-Agent Hierarchy of Needs

Architecture
1

Safety Layer

Validate request shape; trim and bound task length (default 2000 chars); reject malformed JSON.

2

Coordination Layer

Route tasks to agent roles: planner, researcher, executor, reviewer.

3

Capability Layer

Run role-specific tools with clear timeouts, retries, and fallback behaviour.

4

Memory Layer

Persist shared context in Cloudflare KV (MULTI_AGENT_STATE) so agents build on prior work.

5

Outcome Layer

Score outputs, resolve conflicts, and return one unified final response.

Reference Implementation

Cloudflare Workers
multi-agent-worker.js Cloudflare Workers 
const DEFAULT_MAX_TASK_LENGTH = 2000;

export default {
  async fetch(request, env) {
    let payload;
    try {
      payload = await request.json();
    } catch (error) {
      return new Response("Malformed JSON body", { status: 400 });
    }

    if (!payload || typeof payload.task !== "string" || payload.task.trim() === "") {
      return new Response("Missing or invalid task field", { status: 400 });
    }

    // MULTI_AGENT_STATE — Cloudflare KV namespace binding (wrangler.toml)
    const hierarchy = {
      safety:       () => payload.task.trim().slice(0, DEFAULT_MAX_TASK_LENGTH),
      coordination: (task) => ({
        planner:    `Plan: ${task}`,
        researcher: `Research: ${task}`,
        executor:   `Execute: ${task}`,
        reviewer:   `Review: ${task}`,
      }),
      capability:   async (tasks) => tasks,
      memory:       async (result) =>
        await env.MULTI_AGENT_STATE.put("last_result", JSON.stringify(result)),
      outcome:      (result) => ({ status: "complete", result }),
    };

    const safeTask    = hierarchy.safety();
    const coordinated = hierarchy.coordination(safeTask);
    const executed   = await hierarchy.capability(coordinated);
    await hierarchy.memory(executed);
    return Response.json(hierarchy.outcome(executed));
  },
};
